MFD JotForm Widgets

Custom widgets used inside Multiform Defense's NJ firearms intake form. Each widget is loaded into JotForm via the iFrame Embed widget pattern.

ORI Lookup → ori-lookup/

Resolves applicant address → legal NJ municipality → correct ORI (Originating Agency Identifier). Catches the postal-vs-legal-municipality trap, hard-blocks known-dead ORIs, warns on unverified entries with the right NJSP barracks contact email.

Email Typo Check → email-typo-check/

Catches common email-domain typos (gmial → gmail, yahooo → yahoo, hotnail → hotmail, etc.) using Mailcheck + a stuck-key detector for repeat-character typos.
